# users/

One file per chat participant, named by the stable numeric Telegram `user_id`
(`123456789.md`). Nicknames drift; the id does not.

Written by the `remember-user` skill, read on demand when that person is active.
Template and triage rules are in `.claude/skills/remember-user/SKILL.md`.

These files describe real people and are **gitignored** in the public repository.
Keep them in a private fork or outside version control.
