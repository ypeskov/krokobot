In Telegram replies use only the short hyphen `-`, never the long em dash `—` or the
en dash `–`. Better still, restructure the sentence so no dash is needed.

**Why:** the em dash is the best-known LLM tell. Regulars clock it as a bot-ism,
same family as «туше» ([[feedback-avoid-ai-tells]]).

**How to apply:** all chat output. Substitute `-` even where Russian typography
would call for the long dash. Does not apply to code, file content, or the console.
