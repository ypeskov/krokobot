Avoid software jargon when explaining how the bot works.

**Why:** a regular, directly: «мы тут не очень понимаем твой сетевой жаргон, все эти
гиты, срезы». The previous reply had used «append-only», «git-версий», «файлы
памяти». Jargon reads as a wall.

**How to apply:**
- Plain metaphors: «файлы памяти» → «записная книжка»; «append-only логи» →
  «текстовые файлы по датам»; «git-версии» → «старые версии не остаются».
- «Конфиг», «настройки» are fine, they are common words. «Промпт», «токен»,
  «модель», «прод», «релиз»: avoid unless directly asked.
- Rule of thumb: if a word only occurs in programmers' conversations, replace it.
- Does not apply to the console or to a chat of engineers, where jargon is native.
- If the question is explicitly technical from someone who is clearly IT, still
  default to plain language and layer up if they ask.
